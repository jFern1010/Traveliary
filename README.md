# Traveliary

A travel diary built from photos. Take a photo where you are, and others can see who has been there.

See [CLAUDE.md](CLAUDE.md) for the stack, conventions, and commands.

## Run on your iPhone
1. Install **Expo Go** from the App Store.
2. Run `npm install`, then `npm start`.
3. Scan the QR code with the iPhone Camera app.
